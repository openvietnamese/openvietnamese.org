# site/src/taskbook — Instruction Pillar (Taskbook)

*Part of Pillar 3 of three: Instruction. Also reachable via the `instruction/taskbook/` symlink.*

*Intermediate Vietnamese: A Task-Based Journey*: 30 standalone, interactive task pages (M1–M10, three tasks each), published at `openvietnamese.org/taskbook/`.

## Layout

| Path | Purpose |
|---|---|
| `index.html` | book index (table of contents), generated by `_tools/taskbook/build_index.py` |
| `m<module>t<task>.html` | one self-contained page per task (inline CSS/JS, no front matter) |
| `img/` | content images, referenced from pages as `img/<file>` |

Publishing: `.eleventy.js` copies `*.html` and `img/` byte for byte (passthrough) and never templates this folder. That's why this file and anything else here is not published.

## Where things live

| What | Where |
|---|---|
| Original task documents (Google Docs → md, with embedded images) | `site/_source/taskbook/md/` (gitignored) |
| Generator, page sources (`src/mXtY.txt`), checker | `site/_tools/taskbook/` (gitignored). See its README |
| Old Eleventy njk drafts (module-03/04) | `site/_source/taskbook/legacy-njk/` |

## Editing a page

1. Edit `site/_tools/taskbook/src/mXtY.txt` (M7T1–M7T3 are hand-built: edit their HTML directly).
2. `python3 build.py src/mXtY.txt && python3 check.py mXtY`
3. `python3 build_index.py` if a title, subtitle, or tag changed.

Transcripts must stay verbatim (they match the audio). Answer-key corrections are judgment calls: note them for Huy.
